# Security Policy

## Unterstützte Versionen

Sicherheitskorrekturen werden für die jeweils neueste veröffentlichte Version
bereitgestellt. Vor einer Meldung sollte geprüft werden, ob das Problem auch mit
dieser Version auftritt.

## Sicherheitsproblem melden

Bitte veröffentliche Sicherheitslücken, Tokens, Freigabelinks, Standortdaten
oder andere sensible Informationen nicht in einem öffentlichen Issue.

Nutze stattdessen im GitHub-Reiter **Security** die Funktion
**Report a vulnerability**. Beschreibe dort:

- die betroffene Version
- die möglichen Auswirkungen
- nachvollziehbare Schritte zur Reproduktion
- bekannte Maßnahmen zur Begrenzung des Problems

Kompromittierte Zugangsdaten sollten unabhängig von der Meldung sofort
widerrufen und ersetzt werden.
